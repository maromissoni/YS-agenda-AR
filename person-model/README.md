# Person detector

MoveNet SinglePose Lightning by Google (Apache License 2.0, originally published on TensorFlow Hub),
in the TensorFlow.js format converted by the Human library's model collection
(@vladmandic/human-models, MIT License).

It finds 17 body points (nose, shoulders, hips, knees, ankles...) of one person in the camera picture.
It runs only on the phone, only while the portal is open; no picture leaves the phone or is stored.
